# MAGINHAWA website (static, Vercel-ready)

Deploy: drag this folder into vercel.com/new, or run `npx vercel --prod` inside it. No build step. `vercel.json` enables clean URLs (/lookbook, /products, /leather-mule ...).

Pages: index, lookbook, products, about, leather-mule (P1), penny-mule (P2), soft-leather-loafer (P3), chelsea-boots (P4), tabi-loafers (P5).

External links (OTTO Leather Facebook, risquemanufacturing.com) are in about.html.
Colors per product: each product page has a `window.PRODUCT` block near the bottom.
